## Описание проекта
В рамках семестровой работы решены две задачи машинного обучения: **регрессия** и **классификация**. Для каждой задачи выполнен полный цикл работы с данными: первичный анализ, очистка и отбор признаков по матрице корреляций, анализ выбросов (IQR), разделение выборки (60/40), масштабирование, обучение моделей, визуализация графиков, подбор гиперпараметров и итоговое сравнение качества.

## Структура проекта
- **`task1_regression/`** — Задача регрессии (предсказание числового значения `y`, подробный разбор в `README.md`).
- **`task2_classification/`** — Задача классификации (предсказание класса `0`, `1` или `2`, подробный разбор в `README_classification.md`).

## Задача №1: Регрессия
- **Данные:** 100 строк, 7 признаков (`f0–f6`) + целевая переменная `y`.
- **Предобработка:**
  - Удалил `f5` (70% пропусков) и `f6` (корреляция `-0.0389`, шум).
  - Заполнил пропуски в `f4` (5%) медианой.
  - Проверил выбросы методом IQR (единичные выбросы 1–4% оставил из-за малого размера выборки).
  - Разбил данные на `train`/`test` (60/40) и выполнил масштабирование (`StandardScaler`).
- **Модели (оценка по `score()` / $R^2$):**
  - `SVR` (`kernel='linear', C=100, epsilon=5`) — **`0.9657`** (базовая: `0.0537`)
  - `LinearRegression` — **`0.9234`**
  - `RandomForestRegressor` (`n_estimators=50, max_depth=None, min_samples_leaf=1`) — **`0.8851`** (базовая: `0.8809`)
  - `KNeighborsRegressor` (`n_neighbors=1`, сырые данные) — **`0.8071`** (базовая масштабированная: `0.6592`)
- **Результат:** Лучшая модель — настроенный **`SVR` (`R² = 0.9657`)**. Подбор параметров выполнен перебором по сетке значений в циклах с построением графиков зависимости точности.

## Задача №2: Классификация
- **Данные:** 100 строк, 7 признаков (`f0–f6`) + целевой столбец `target` (3 сбалансированных класса: `0`, `1`, `2`).
- **Предобработка:**
  - Удалил полный дубликат `f6` (корреляция `1.00` с `f3`) и шумовые признаки `f2`, `f5` (корреляция `-0.02` и `-0.08`).
  - Заполнил пропуски в `f0` и `f1` (по 5%) медианой.
  - Проверил выбросы методом IQR (в `f3` всего 2%, в остальных `0%`).
  - Разбил данные на `train`/`test` (60/40) с сохранением баланса классов (`stratify=y`) и выполнил масштабирование (`StandardScaler`).
- **Модели (оценка по `score()` / `Accuracy` и `F1-score`):**
  - `KNeighborsClassifier` (`n_neighbors=5, weights='uniform'`, сырые данные) — **`Accuracy = 0.9250`**, `F1-score = 0.9265` (базовая масштабированная: `0.8000`)
  - `RandomForestClassifier` (`n_estimators=50, max_depth=3, min_samples_leaf=4`) — **`Accuracy = 0.8250`**, `F1-score = 0.8211` (базовая: `0.8000`)
- **Результат:** Лучшая модель — настроенный **`KNeighborsClassifier` на сырых данных (`Accuracy = 0.9250`)**. Проведён подбор гиперпараметров, построены графики зависимости качества от параметров и матрицы ошибок (`Confusion Matrix`).
