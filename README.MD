## Описание проекта
В рамках семестровой работы были решены две задачи машинного обучения: регрессия и классификация. Для каждой задачи проведен полный цикл анализа данных, предобработка, обучение моделей и оценка их качества.

## Структура проекта
- **`task1_regression/`** — Задача регрессии (предсказание числового значения).
- **`task2_classification/`** — Задача классификации (предсказание категории).

## Использованные технологии и библиотеки
- **Язык:** Python 3
- **Обработка данных:** `pandas`, `numpy`
- **Визуализация:** `matplotlib`, `seaborn`
- **Машинное обучение:** `scikit-learn`ы

## Задача №1: Регрессия
- **Данные:** 100 строк, 7 признаков + 1 целевая переменная.
- **Предобработка:** Заполнение пропусков медианой, удаление неинформативных признаков (f5, f6).
- **Модели:** 
  - `LinearRegression`
  - `RandomForestRegressor`
  - `KNeighborsRegressor`
  - `SVR`
- **Результат:** Лучшая модель — **LinearRegression (R² = 0.9234)**. Подбор гиперпараметров проводился через `GridSearchCV`.

## Задача №2: Классификация
- **Данные:** 100 строк, 7 признаков + 1 целевая переменная (3 класса).
- **Предобработка:** Заполнение пропусков медианой, удаление дубликата (f6).
- **Модели:** 
  - `RandomForestClassifier`
  - `KNeighborsClassifier`
- **Результат:** Лучшая модель — **RandomForestClassifier (Accuracy = 0.8000)**. Проведен подбор гиперпараметров.
